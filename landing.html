Quick Start

Bắt đầu trong 3 bước

Copy framework vào project của bạn, khởi tạo memory system, và bắt đầu sử dụng. Toàn bộ setup tự động qua scripts.

1

Copy Framework

Copy `.cursor/` directory vào root của project hoặc clone repository chính thức.

git clone https://github.com/.../cursor-enterprise-framework.git
2

Build Memory

Chạy scripts để khởi tạo SQLite databases, build code index và knowledge embeddings.

. .cursor/scripts/memory-builder/build-memory.ps1
3

Start Coding

Mở project trong Cursor, bắt đầu task mới. Framework tự động load context, rules và knowledge.

1. Open project in Cursor 2. Start new chat 3. CEF auto-loads context
