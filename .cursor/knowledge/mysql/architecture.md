## 1. Tổng quan Kiến trúc

### 1.1 MySQL Architecture Overview

MySQL là một relational database management system (RDBMS) sử dụng client-server architecture. Nó được thiết kế modular với nhiều layers làm việc cùng nhau.

Core components:
- **Connection Layer**: Handle client connections và authentication
- **SQL Layer**: Parse, optimize, và execute queries
- **Storage Engine Layer**: Manage data storage và retrieval
- **Physical Layer**: File system và disk I/O

### 5.2 Replication Formats

| Format | Description | Use Case |
|--------|-------------|----------|
| SBR (Statement) | SQL statements replicated | Simple DDL, less data transfer |
| RBR (Row) | Row changes replicated | Complex updates, consistency |
| MBR (Mixed) | Auto-selects SBR or RBR | Best of both worlds |
