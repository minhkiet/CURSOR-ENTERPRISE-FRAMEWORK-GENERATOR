# PGVector Glossary - Từ Điển Thuật Ngữ PGVector

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành PGVector extension cho PostgreSQL.

## Các thuật ngữ cơ bản

### 1. Vector Embeddings

Vector embeddings là numerical representations của data (text, images). Generated by ML models. Similar items có similar vectors.

### 2. PGVector Extension

PGVector là PostgreSQL extension cho vector similarity search. Cung cấp vector data type, operators, indexes. Open-source.

### 3. Similarity Search

Tìm kiếm items tương tự dựa trên vector distance. Euclidean, cosine, dot product distances. Essential cho semantic search.

### 4. HNSW Index

Hierarchical Navigable Small World là algorithm cho approximate nearest neighbor search. Fast queries, high recall. Memory-intensive.

### 5. IVFFlat Index

Inverted File Index là algorithm cho approximate nearest neighbor. Faster build time. Good recall.

### 6. Exact Search

Exact nearest neighbor search. 100% recall. Slow on large datasets.

### 7. Dimensions

Vector dimensions là số lượng elements trong vector. Typically 384-3072 for text embeddings.

### 8. Distance Functions

- L2 distance (Euclidean)
- Cosine distance
- Inner product

## Kết luận

PGVector enables vector search in PostgreSQL.
