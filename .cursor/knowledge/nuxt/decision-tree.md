# Nuxt Decision Tree - Cây Quyết Định Nuxt

## Quyết định về Rendering

### Câu hỏi: Chọn rendering mode nào?

- **SSG**: Content tĩnh, docs, blogs
- **SSR**: Dynamic content, personalized
- **Hybrid**: Mix của cả hai

## Quyết định về Modules

### Câu hỏi: Cần modules nào?

- **@nuxt/image**: Image optimization
- **@nuxt/content**: Markdown content
- **@nuxt/tailwindcss**: Styling
- **@nuxtjs/google-fonts**: Fonts

## Quyết định về Deployment

### Câu hỏi: Deploy ở đâu?

- **Vercel**: Serverless, easy
- **Netlify**: Serverless, edge
- **Self-hosted**: Node.js, Docker

## Summary

Nuxt 3 + Vercel là recommended setup.
