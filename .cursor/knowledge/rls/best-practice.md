# RLS Best Practices - Thực Hành Tốt Nhất

## Best Practices

### 1. Always Enable RLS

- Enable RLS on all tables
- Test with anon key
- Verify row visibility

### 2. Create Policies

- Separate policies per operation
- Clear policy names
- Document policy logic

### 3. Performance

- Index columns in policies
- Avoid complex conditions
- Test policy performance

## Kết luận

RLS best practices ensure security without performance impact.
