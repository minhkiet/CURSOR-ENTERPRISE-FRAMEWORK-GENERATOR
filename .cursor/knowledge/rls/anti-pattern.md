# RLS Anti-Patterns - Các Mẫu Cần Tránh

## Anti-Patterns

### 1. No RLS

**Mô tả**: Không enable RLS on tables.

**Giải pháp**: Always enable RLS.

### 2. Overly Permissive Policies

**Mô tả**: Policies allow all access.

**Giải pháp**: Create restrictive policies.

## Kết luận

Tránh các anti-patterns này giúp RLS security tốt hơn.
