# Laravel Checklist - Danh Sách Kiểm Tra Laravel

## Checklist

### Setup

- [ ] Laravel project installed
- [ ] Environment configured
- [ ] Database connected
- [ ] Cache driver configured

### Code

- [ ] Models with relationships
- [ ] Migrations created
- [ ] Controllers organized
- [ ] Routes defined
- [ ] Middleware configured

### Testing

- [ ] Unit tests
- [ ] Feature tests
- [ ] Database tests
- [ ] API tests

### Security

- [ ] CSRF protection
- [ ] Mass assignment
- [ ] Validation
- [ ] Auth implemented

## Kết luận

Use this checklist during Laravel development.
