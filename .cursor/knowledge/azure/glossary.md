# Azure Glossary - Từ Điển Thuật Ngữ Microsoft Azure

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành Microsoft Azure cloud platform.

## Các thuật ngữ cơ bản

### 1. Azure

Microsoft Azure là cloud computing platform. Compute, storage, networking, AI services. Global infrastructure.

### 2. Resource Group

Resource Group là container cho Azure resources. Logical grouping. Same lifecycle, billing.

### 3. Virtual Machine

Virtual Machine (VM) là on-demand, scalable computing. Windows, Linux. Pay per second.

### 4. App Service

App Service là fully managed platform. Web apps, REST APIs. Auto-scaling, deployment slots.

### 5. Azure Functions

Azure Functions là serverless compute. Event-driven. Pay per execution.

### 6. Azure SQL

Azure SQL là fully managed SQL database. PaaS. Always encrypted. Automatic backups.

### 7. Blob Storage

Blob Storage là object storage for unstructured data. Images, videos, documents. Tiered storage.

### 8. Azure Cosmos DB

Cosmos DB là globally distributed database. Multiple models. SLA-backed throughput.

### 9. Azure Kubernetes Service (AKS)

AKS là managed Kubernetes service. Container orchestration. Auto-scaling.

### 10. Azure DevOps

Azure DevOps là development lifecycle tools. Boards, repos, pipelines. CI/CD.

### 11. Azure AD

Azure AD là identity and access management. SSO, MFA. Conditional access.

### 12. ARM Templates

ARM Templates là Infrastructure as Code. JSON-based. Declarative deployment.

### 13. Azure CDN

Azure CDN là content delivery network. Global presence. Custom domains, SSL.

## Kết luận

Azure Glossary cung cấp nền tảng về Azure services.
