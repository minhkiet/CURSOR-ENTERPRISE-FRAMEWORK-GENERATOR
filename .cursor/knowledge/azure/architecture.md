# Azure Architecture - Kiến Trúc Azure

## Tổng quan

Microsoft Azure là cloud platform cung cấp compute, storage, networking, AI services.

## Kiến trúc chi tiết

### 1. Common Services

- **Compute**: VMs, App Service, Functions, AKS
- **Storage**: Blob, Files, Queues, Tables
- **Database**: SQL, Cosmos DB, MySQL, PostgreSQL
- **Networking**: VNet, Load Balancer, Application Gateway

### 2. Architecture Patterns

- **Microservices**: AKS, Functions
- **Serverless**: Functions, Logic Apps
- **Data**: Cosmos DB, Data Factory

## Kết luận

Azure architecture enables enterprise cloud solutions.
