# Vector Search FAQ - Câu Hỏi Thường Gặp

## Câu Hỏi Cơ Bản

### 1. Vector search là gì?

Vector search là kỹ thuật tìm kiếm using numerical vectors. Similar items có vectors gần nhau.

### 2. ANN là gì?

ANN (Approximate Nearest Neighbor) là algorithms cho fast similarity search. Trade accuracy for speed.

## Câu Hỏi Kỹ Thuật

### 3. HNSW vs IVF?

HNSW better recall, slower build. IVF faster build, good recall.

### 4. Distance metrics nào?

Cosine similarity, Euclidean distance, dot product. Choose based on use case.
