# Vector Search Glossary - Từ Điển Thuật Ngữ

## Các thuật ngữ cơ bản

### 1. Vector Search

Vector search là kỹ thuật tìm kiếm using numerical vectors. Similar items có vectors gần nhau. Essential cho semantic search.

### 2. Embeddings

Embeddings là vectors representing data. Generated by ML models. Text, images, audio đều có thể embed.

### 3. Similarity Metrics

- Cosine similarity: angle between vectors
- Euclidean distance: straight-line distance
- Dot product: projection

### 4. Approximate NN

Approximate nearest neighbor algorithms. HNSW, IVF, LSH. Trade accuracy for speed.

### 5. ANN Index

Approximate nearest neighbor index. Enable fast search on large datasets.

## Kết luận

Vector search là core của semantic search systems.
