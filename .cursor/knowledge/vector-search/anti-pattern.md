# Vector Search Anti-Patterns - Các Mẫu Cần Tránh

## Anti-Patterns

### 1. Wrong Index Type

**Mô tả**: Sử dụng wrong index type.

**Giải pháp**: Choose based on data size.

### 2. No Indexing

**Mô tả**: Search without index.

**Giải pháp**: Create appropriate index.

## Kết luận

Tránh các anti-patterns này giúp vector search performance tốt hơn.
