# PDF FAQ - Câu Hỏi Thường Gặp PDF

## Câu Hỏi Cơ Bản

### 1. PDF là gì?

PDF (Portable Document Format) là file format developed by Adobe. Platform-independent, preserves formatting.

### 2. PDF parsing là gì?

PDF parsing là extracting content from PDF files. Text, images, metadata.

## Câu Hỏi Kỹ Thuật

### 3. Library nào tốt nhất?

pdf.js cho browser, pdf-parse cho Node.js.

### 4. OCR là gì?

OCR (Optical Character Recognition) cho phép extract text từ scanned PDFs.
