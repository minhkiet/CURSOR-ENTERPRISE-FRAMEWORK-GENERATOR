# PDF Glossary - Từ Điển Thuật Ngữ PDF Processing

## Các thuật ngữ cơ bản

### 1. PDF

PDF (Portable Document Format) là file format developed by Adobe. Platform-independent, preserves formatting.

### 2. Parsing

PDF parsing là extracting text, images, metadata from PDF. Libraries: pdf.js, pdf-parse.

### 3. Extraction

Content extraction: text, tables, images, fonts. OCR for scanned PDFs.

### 4. Generation

PDF generation tạo PDF from HTML, images, data. Libraries: puppeteer, weasyprint.

## Kết luận

PDF Glossary cung cấp nền tảng về PDF processing.
