# PDF Decision Tree - Cây Quyết Định PDF

## Quyết định về Library

### Câu hỏi: Library nào?

- **pdf.js**: Browser
- **pdf-parse**: Node.js
- **puppeteer**: HTML to PDF

## Quyết định về Features

- **Text extraction**: Native
- **Table extraction**: Specialized libraries
- **OCR**: Tesseract

## Summary

pdf-parse + Tesseract là common approach.
