# AWS Glossary - Từ Điển Thuật Ngữ Amazon Web Services

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành Amazon Web Services cloud platform.

## Các thuật ngữ cơ bản

### 1. AWS

AWS (Amazon Web Services) là cloud platform từ Amazon. Largest cloud provider. 200+ services.

### 2. EC2

EC2 (Elastic Compute Cloud) là scalable virtual servers. Multiple instance types. Pay per use.

### 3. S3

S3 (Simple Storage Service) là object storage. 11 9's durability. Tiers: Standard, IA, Glacier.

### 4. Lambda

Lambda là serverless compute. Event-driven. Pay per invocation.

### 5. ECS/EKS

ECS là container orchestration. EKS là managed Kubernetes. Fargate for serverless containers.

### 6. RDS

RDS là managed relational database. MySQL, PostgreSQL, Oracle, SQL Server. Multi-AZ.

### 7. DynamoDB

DynamoDB là fully managed NoSQL database. Single-digit latency. Serverless option.

### 8. CloudFront

CloudFront là CDN. Global network. Edge locations.

### 9. IAM

IAM (Identity and Access Management) là security. Users, roles, policies. Least privilege.

### 10. VPC

VPC (Virtual Private Cloud) là isolated network. Subnets, route tables, gateways.

### 11. CloudFormation

CloudFormation là Infrastructure as Code. Templates, stacks.

### 12. SQS/SNS

SQS là managed message queuing. SNS là pub/sub messaging.

### 13. Step Functions

Step Functions là serverless workflow. State machines. Visual workflow editor.

## Kết luận

AWS Glossary cung cấp nền tảng về AWS services.
