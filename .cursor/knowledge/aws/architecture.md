# AWS Architecture - Kiến Trúc AWS

## Tổng quan

Amazon Web Services (AWS) là cloud platform với 200+ services cho compute, storage, AI, và more.

## Kiến trúc chi tiết

### 1. Common Services

- **Compute**: EC2, Lambda, ECS, EKS
- **Storage**: S3, EBS, EFS
- **Database**: RDS, DynamoDB, ElastiCache
- **Networking**: VPC, CloudFront, Route 53

### 2. Well-Architected Framework

- Operational Excellence
- Security
- Reliability
- Performance Efficiency
- Cost Optimization
- Sustainability

## Kết luận

AWS architecture enables scalable cloud solutions.
