# Claude FAQ - Câu Hỏi Thường Gặp

## Câu Hỏi Cơ Bản

### 1. Claude là gì?

Claude là AI assistant từ Anthropic. Known for helpful, harmless, honest responses.

### 2. Claude 3 vs Claude 2?

Claude 3 là latest version với improved reasoning, vision capabilities. Opus, Sonnet, Haiku variants.

### 3. Constitutional AI là gì?

Constitutional AI là training approach sử dụng principles để guide model behavior.

### 4. Tool use là gì?

Tool use cho phép Claude interact với external tools như web search, calculations.

### 5. Prompt caching?

Prompt caching giảm latency bằng cách cache frequently used prompts.
