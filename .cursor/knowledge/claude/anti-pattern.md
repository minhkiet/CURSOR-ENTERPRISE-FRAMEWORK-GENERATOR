# Claude Anti-Patterns - Các Mẫu Cần Tránh

## Anti-Patterns

### 1. Long Prompts

**Mô tả**: Send too much context.

**Giải pháp**: Summarize, optimize.

### 2. No Error Handling

**Mô tả**: Ignore API errors.

**Giải phól**: Implement retry logic.

## Kết luận

Tránh các anti-patterns này giúp Claude usage tốt hơn.
