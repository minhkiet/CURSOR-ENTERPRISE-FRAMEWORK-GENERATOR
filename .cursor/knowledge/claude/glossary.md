# Claude Glossary - Từ Điển Thuật Ngữ Anthropic Claude

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành Claude AI từ Anthropic.

## Các thuật ngữ cơ bản

### 1. Claude

Claude là family of AI assistants từ Anthropic. Known for helpful, harmless, honest responses. Available via API và Claude.ai.

### 2. Constitutional AI

Constitutional AI là training approach sử dụng principles để guide model behavior. Self-critique, helpfulness, harmlessness.

### 3. Claude API

Claude API cho phép integrate Claude vào applications. Models: Claude, Claude Instant. Tokens, streaming, system prompts.

### 4. Anthropic SDK

Official SDK for Claude API. Available in Python, TypeScript. Simplifies API integration.

### 5. Tool Use

Tool use cho phép Claude interact với external tools. Web search, calculations, code execution.

### 6. Prompt Caching

Prompt caching giảm latency và cost bằng cách cache frequently used prompts. Claude supports persistent message histories.

## Kết luận

Claude Glossary cung cấp nền tảng về Anthropic Claude.
