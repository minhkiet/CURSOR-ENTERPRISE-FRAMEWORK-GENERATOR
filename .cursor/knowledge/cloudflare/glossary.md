# Cloudflare Glossary - Từ Điển Thuật Ngữ Cloudflare

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành Cloudflare services.

## Các thuật ngữ cơ bản

### 1. CDN

CDN (Content Delivery Network) là distributed network of servers. Caches content globally. Faster delivery.

### 2. Workers

Cloudflare Workers là serverless JavaScript functions. Run at edge, close to users. Low latency.

### 3. Pages

Cloudflare Pages là static site hosting. Git integration. Fast, secure.

### 4. R2 Storage

R2 Storage là object storage without egress fees. S3-compatible API. Durable.

### 5. D1 Database

D1 là serverless SQLite database. Global replication. Query with Drizzle ORM.

### 6. KV

Workers KV là distributed key-value storage. Global, low latency. Eventual consistency.

### 7. Durable Objects

Durable Objects là strongly consistent objects. Single-writer semantics. Real-time apps.

### 8. Workers AI

Workers AI là AI inference at the edge. Run ML models globally. Serverless.

### 9. RAIL

Railgun là cache optimization technology. Dynamic content caching.

### 10. Zero Trust

Cloudflare Zero Trust là security platform. SASE, SSE services. Identity-based access.

## Kết luận

Cloudflare Glossary cung cấp nền tảng về Cloudflare services.
