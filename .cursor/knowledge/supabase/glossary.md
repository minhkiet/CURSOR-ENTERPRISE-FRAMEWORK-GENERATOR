# Supabase Glossary - Từ Điển Thuật Ngữ Supabase

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành Supabase.

## Các thuật ngữ cơ bản

### 1. Supabase

Supabase là open-source Firebase alternative. Cung cấp PostgreSQL database, authentication, realtime subscriptions, storage, edge functions.

### 2. PostgreSQL

Supabase dựa trên PostgreSQL. Tất cả PostgreSQL features được supported. Full SQL support.

### 3. Authentication

Supabase Auth: Email/password, OAuth providers, Magic links. JWT tokens. Row Level Security integration.

### 4. Row Level Security (RLS)

RLS là PostgreSQL feature cho phép row-level access control. Policies determine access. Supabase Auth integration.

### 5. Realtime

Realtime subscriptions thay đổi database. PostgreSQL changes broadcast via WebSocket. Filter by table, filter by columns.

### 6. Storage

File storage với buckets. Public và private buckets. Image transformations. CDN integration.

### 7. Edge Functions

Edge Functions là serverless TypeScript functions. Deploy to edge locations. Deno runtime.

### 8. Dashboard

Supabase Dashboard cho quản lý database, auth, storage, realtime. Table editor, SQL editor, logs.

### 9. PostgREST

PostgREST tạo REST API tự động từ PostgreSQL. CRUD operations. Filtering, sorting, pagination.

### 10. GoTrue

GoTrue là authentication server. SMTP-based. OAuth2 providers.

## Kết luận

Từ điển này cung cấp nền tảng về Supabase.
