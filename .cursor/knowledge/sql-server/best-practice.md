# SQL Server Best Practices - Thực Hành Tốt Nhất

## Best Practices

### 1. Indexing

- Clustered vs non-clustered
- Covering indexes
- Index maintenance
- Avoid too many indexes

### 2. Query Optimization

- Use execution plans
- Avoid SELECT *
- Proper joins
- Table hints carefully

### 3. Security

- Principle of least privilege
- Encrypted connections
- Row-level security
- Proper ownership

### 4. Backup Strategy

- Full backups
- Transaction log backups
- Point-in-time recovery
- Test restores

## Kết luận

Following these practices ensures optimal SQL Server performance.
