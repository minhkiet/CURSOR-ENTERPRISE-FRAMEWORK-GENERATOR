# OpenAI Decision Tree - Cây Quyết Định

## Quyết định về Model

### Câu hỏi: Model nào?

- **GPT-4**: Complex reasoning, large context
- **GPT-3.5 Turbo**: Simple tasks, cost-effective

## Quyết định về Parameters

### Câu hỏi: Temperature nào?

- **0**: Factual, deterministic
- **0.7**: Balanced
- **1**: Creative

## Quyết định về Features

- **Function Calling**: Structured output
- **Embeddings**: Semantic search
- **Fine-tuning**: Custom models

## Summary

GPT-4 + proper parameters là recommended approach.
