# Bát Cửu Linh Số - Decision Tree (Cây Quyết Định)

## Tổng Quan

Cây quyết định này giúp phân tích nhanh bất kỳ dãy số nào theo hệ thống Bát Cửu Linh Số. Tuân theo trình tự: Điểm → Tuyến → Diện → Thể.

## Chi Tiết Từng Bước

### Bước 1: Xác Định Độ Dài Số

```
Quyết định:
├─ 4-6 chữ số
│   └─ Biển số xe, số nhà → Phân tích toàn bộ
│
├─ 7-10 chữ số
│   └─ Số điện thoại → Ưu tiên 4-6 số cuối
│
└─ 11+ chữ số
    └─ Phân tích từng phần (đầu, giữa, cuối)
```

### Bước 2: Chia Số Thành Cặp

```
Ví dụ: 0901234567

Cách chia:  09 | 01 | 23 | 45 | 67
            ─┬─ ─┬─ ──┬─ ──┬─ ──┬─
             │   │    │    │    │
             09  01   23   45   67

Quy tắc:
├─ Chia từ TRÁI sang PHẢI
├─ Mỗi cặp có 2 chữ số
└─ Số lẻ cuối → Cặp cuối là 1 chữ số (xử lý đặc biệt)
```

## Decision Tree Cho Các Loại Số Cụ Thể

### Số Điện Thoại

```
┌─────────────────────────────────────────────────────────────────┐
│                    SỐ ĐIỆN THOẠI                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  Đầu số (090, 084...)                                          │
│  └─ Thường không ảnh hưởng nhiều                              │
│                                                                 │
│  Phần chính (4-6 số cuối)                                      │
│  ├─ Ưu tiên phân tích                                          │
│  └─ Chiếm 60% năng lượng                                       │
│                                                                 │
│  CHECKLIST:                                                    │
│  ├─ □ 4-6 số cuối là Cát tinh?                                │
│  ├─ □ Có kết hợp 1319 (Thiên Y + Diên Niên)?                  │
│  ├─ □ Hung tinh có được hóa giải?                              │
│  ├─ □ Không có 1812 hoặc 1218?                                 │
│  ├─ □ Không quá nhiều số 0 (3+)?                              │
│  └─ □ Không quá nhiều số 5 (3+) hoặc 5 ở vị trí xấu?         │
│                                                                 │
│  QUYẾT ĐỊNH:                                                   │
│  ├─ PASS (6/6) → Số tốt, nên dùng                            │
│  ├─ PASS (4-5/6) → Số khá, có thể dùng                       │
│  ├─ PASS (2-3/6) → Cân nhắc, cần cải thiện                   │
│  └─ PASS (0-1/6) → Nên thay đổi                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
