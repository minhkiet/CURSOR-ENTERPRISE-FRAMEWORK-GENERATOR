# FAQ - Hỏi Đáp về Hệ Thống Tử Vi

## 1. Câu Hỏi Chung

### Q1: Tử Vi khác gì so với Bát Tự (Bazi)?

**A:** Tử Vi và Bát Tự đều là hệ thống bói toán phương Đông, nhưng có sự khác biệt:

| Tiêu chí | Tử Vi | Bát Tự |
|----------|-------|--------|
| **Nguồn gốc** | Trung Quốc, phát triển đầy đủ | Trung Quốc, cổ xưa hơn |
| **Đơn vị phân tích** | 12 Cung + Sao + Vận hạn | Tứ Trụ (4 cột) |
| **Độ chính xác thời gian** | Tính theo giờ | Tính theo giờ |
| **Phương pháp** | Sao chiếu mệnh, cung điện | Can Chi, Ngũ Hành |
| **Phức tạp** | Cao (nhiều yếu tố) | Trung bình |
| **Ứng dụng** | Phân tích chi tiết toàn diện | Tính cách, vận mệnh cơ bản |

**Tử Vi** sử dụng:
- 12 Cung điện (Mệnh, Phụ Mẫu, Phúc Đức...)
- Hơn 100 sao (Tử Vi, Thái Dương, Thái Âm...)
- Vận hạn (Thiên, Nhân, Địa vận)
- Hóa quyền (Lộc, Khoa, Quyền)

**Bát Tự** sử dụng:
- Tứ Trụ (Năm, Tháng, Ngày, Giờ)
- Thiên Can + Địa Chi
- Ngũ Hành tương sinh/tương khắc
- Cung Mệnh + Nạp Âm

### Q2: Làm thế nào để xác định Cung Mệnh trong Tử Vi?

**A:** Cung Mệnh được xác định dựa vào **Ngày Can** và **Giới tính**:

**Bảng xác định Cung Mệnh (Nam):**

| Ngày Can | Cung Mệnh |
|---------|-----------|
| Giáp, Kỷ | Mệnh (Kim) |
| Ất, Canh | Phụ Mẫu (Thổ) |
| Bính, Tân | Phúc Đức (Thổ) |
| Đinh, Nhâm | Điền Trạch (Thổ) |
| Mậu, Quý | Quan Lộc (Kim) |

**Bảng xác định Cung Mệnh (Nữ):**

| Ngày Can | Cung Mệnh |
|---------|-----------|
| Giáp, Kỷ | Quan Lộc (Kim) |
| Ất, Canh | Điền Trạch (Thổ) |
| Bính, Tân | Phúc Đức (Thổ) |
| Đinh, Nhâm | Phụ Mẫu (Thổ) |
| Mậu, Quý | Mệnh (Kim) |

**Cách tính:**
1. Xác định Ngày Can Chi (dựa vào âm lịch)
2. Tra bảng theo giới tính
3. Vị trí Cung Mệnh xác định vị trí 11 Cung còn lại (xoay ngược chiều kim đồng hồ)

### Q3: Các Sao trong Tử Vi được phân loại như thế nào?

**A:** Sao trong Tử Vi được phân thành nhiều loại:

**1. Sao Chính (Sao Chiếu):**
- Tử Vi, Thiên Cơ, Thái Dương, Thái Âm
- Lộc Tồn, Liêm Trinh, Xương Cu, Khúc Cu
- Cự Môn, Đà La, Kình Dương, Tang Môn

**2. Sao Phụ:**
- Văn Xương, Văn Khúc
- Tả Phụ, Hữu Bật
- Tam Thai, Bát Tọa
- Thiên Hỷ, Thiên Quý

**3. Bát Quái:**
- Tứ Quái, Ngũ Quái, Lục Hợp

**4. Sao Hóa:**
- Hóa Lộc, Hóa Quyền, Hóa Khoa, Hóa Kiếp

**5. Theo Hành:**
- Hỏa: Thái Dương, Liêm Trinh, Hỏa Linh
- Thủy: Thái Âm, Thiên Đồng, Đà La
- Kim: Văn Xương, Văn Khúc, Cự Môn
- Mộc: Thiên Cơ, Tả Phụ, Hữu Bật
- Thổ: Tử Vi, Lộc Tồn, Kình Dương

### Q4: Vận hạn trong Tử Vi được tính như thế nào?

**A:** Vận hạn gồm 3 giai đoạn:

**1. Thiên Vận (0-39 tuổi):**
- Bắt đầu từ năm sinh (Nam) hoặc năm sinh + 1 (Nữ)
- Mỗi vận kéo dài 10 năm
- 4 Thiên Vận

**2. Nhân Vận (40-79 tuổi):**
- Tiếp theo Thiên Vận
- 4 Nhân Vận

**3. Địa Vận (80-120 tuổi):**
- Tiếp theo Nhân Vận
- 4 Địa Vận

**Các Hạn trong mỗi Vận:**
- 12 Thiên Hạn: Tràng Sinh, Mộc Dục, Quan Đới, Mộc Trì, Mộc Tàng, Hoang Vu, Kiếp Tài, Ngũ Bất, Tử Thọ, Phúc Dương, Đại Hao, Thiên Khốc
- 12 Nhân Hạn: Tuệ Giải, Tài Trì, Lâm Quan, Lâm Chung, Quang Hữu, Bế Quan, Tiến Sĩ, Xuất Sĩ, Thanh Long, Phúc Sinh, Hỷ Khúc, Cát Khánh
- 12 Địa Hạn: Kim Tài, Ngọc Bảo, Bảo Khương, Bảo Hợp, Long Đức, Phượng Uyển, Phượng Đới, Hội Xá, Thiên Tài, Địa Tài, Lộc Khố, Hà Mã

## 2. Câu Hỏi Kỹ Thuật

### Q5: Hệ thống Tử Vi xử lý tháng nhuận như thế nào?

**A:** Tháng nhuận âm lịch được xử lý theo quy tắc:

**Xác định tháng nhuận:**
```typescript
interface LunarDate {
  year: number;
  month: number;
  day: number;
  isLeapMonth: boolean;  // Flag cho biết có phải tháng nhuận không
}

// Trong âm lịch, một số tháng có thể xuất hiện 2 lần
// Tháng xuất hiện lần 2 được đánh dấu là leap month
```

**Xử lý trong Tử Vi:**
1. **Xác định tháng chính:** Nếu là tháng nhuận, xác định tháng nào được lặp lại
2. **Tính Sao:** Sao nhập cung theo tháng chính (không tính leap)
3. **Vận hạn:** Vận hạn tính theo năm, không ảnh hưởng bởi tháng nhuận

**Ví dụ:**
- Năm 2023 có tháng 2 nhuận (âm lịch)
- Nếu sinh vào tháng 2 nhuận, vẫn tính là tháng 2 cho Sao

### Q6: Công thức tính vị trí Sao như thế nào?

**A:** Sao được xác định vị trí dựa vào 4 yếu tố:

**1. Theo Ngày (Nhập cung):**
```typescript
// Sao nhập cung theo Ngày Can Chi
const dayPosition = (dayCanIndex * 12 + dayChiIndex) % 12;
```

**2. Theo Tháng (Xuất hiện):**
```typescript
// Sao xuất hiện theo Tháng
const monthPosition = (birthMonth + 1) % 12;
```

**3. Theo Năm (Tính chất):**
```typescript
// Sao mang tính chất năm
const yearPosition = (birthYear + birthMonth) % 12;
```

**4. Theo Giờ (Phụ sao):**
```typescript
// Sao phụ nhập cung theo Giờ
const hourPosition = Math.floor(birthHour / 2) % 12;
```

**Sắp xếp vào 12 Cung:**
```typescript
function arrangeStars(
  dayStars: Sao[],
  monthStars: Sao[],
  yearStars: Sao[],
  cungMenhIndex: number
): Record<CungName, Sao[]> {
  // Bắt đầu từ Cung Mệnh, xoay ngược chiều kim đồng hồ
  const cungs = ['Mệnh', 'Phụ Mẫu', 'Phúc Đức', ...];
  
  // Sắp xếp sao vào các cung
  return assignToCungs(cungs, dayStars, monthStars, yearStars, cungMenhIndex);
}
```

### Q7: Hệ thống xác định Sao chiếm cung như thế nào?

**A:** "Sao chiếm cung" là sao chính đầu tiên trong cung:

**Quy tắc:**
1. Sao chính (type = 'chinh') đầu tiên trong cung là "Sao chiếm cung"
2. Nếu không có sao chính → Cung trống
3. Sao chiếu cung quyết định tính chất của cung đó

**Ví dụ:**
```typescript
interface Cung {
  name: CungName;
  stars: Sao[];
  isEmpty: boolean;      // true nếu không có sao chính
  occupant: string | undefined;  // Tên sao chiếm cung
}

function determineOccupant(cung: Cung): string | undefined {
  const chinhSao = cung.stars.find(s => s.type === 'chinh');
  return chinhSao?.name;
}

// Nếu cung có Tử Vi → Cung Mệnh đầy đủ, quý nhân
// Nếu cung trống → Cung yếu, thiếu vắng
```

### Q8: Mối quan hệ giữa Sao và Ngũ Hành trong Tử Vi?

**A:** Ngũ Hành ảnh hưởng đến:

**1. Tương hợp Sao-Mệnh:**
```typescript
const SAO_ELEMENT = {
  // Hỏa
  'Thái Dương': 'Hỏa',
  'Liêm Trinh': 'Hỏa',
  'Hỏa Linh': 'Hỏa',
  
  // Thủy
  'Thái Âm': 'Thủy',
  'Thiên Đồng': 'Thủy',
  'Đà La': 'Thủy',
  
  // Kim
  'Văn Xương': 'Kim',
  'Văn Khúc': 'Kim',
  'Cự Môn': 'Kim',
  
  // Mộc
  'Thiên Cơ': 'Mộc',
  'Tả Phụ': 'Mộc',
  'Hữu Bật': 'Mộc',
  
  // Thổ
  'Tử Vi': 'Thổ',
  'Lộc Tồn': 'Thổ',
  'Kình Dương': 'Thổ'
};
```

**2. Tương sinh/Tương khắc:**
- Sao cùng hành với Mệnh → Tương hợp, may mắn
- Sao tương sinh với Mệnh → Hỗ trợ
- Sao tương khắc với Mệnh → Xung đột, khó khăn

**3. Ứng dụng:**
```typescript
function analyzeSaoMenhCompatibility(
  menhElement: Element,
  saos: Sao[]
): CompatibilityResult {
  const compatible = saos.filter(s => 
    isSameElement(s.element, menhElement) ||
    isGenerative(s.element, menhElement)
  );
  
  const conflicting = saos.filter(s => 
    isControlling(s.element, menhElement)
  );
  
  return { compatible, conflicting };
}
```

## 3. Câu Hỏi Triển Khai

### Q9: Nên sử dụng database nào cho Tử Vi?

**A:** Khuyến nghị PostgreSQL với JSONB:

**Schema:**
```sql
-- Main chart table
CREATE TABLE tuvi_charts (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  birth_date DATE NOT NULL,
  birth_time TIME NOT NULL,
  timezone VARCHAR(50) NOT NULL,
  gender VARCHAR(10) NOT NULL,
  
  -- Mệnh cách
  menh_name VARCHAR(50),
  menh_element VARCHAR(10),
  
  -- Vị trí Cung Mệnh
  cung_menh_index INT,
  
  -- Metadata
  created_at TIMESTAMP DEFAULT NOW()
);

-- Cung data (JSONB cho flexibility)
CREATE TABLE chart_cungs (
  chart_id UUID REFERENCES tuvi_charts(id),
  cungs_data JSONB
);

-- Sao positions (JSONB)
CREATE TABLE chart_saos (
  chart_id UUID REFERENCES tuvi_charts(id),
  saos_data JSONB
);

-- Indexes
CREATE INDEX idx_tuvi_user ON tuvi_charts(user_id);
CREATE INDEX idx_tuvi_menh ON tuvi_charts(menh_element);
CREATE INDEX idx_tuvi_birth ON tuvi_charts(birth_date);
```

**Ưu điểm của PostgreSQL:**
- JSONB cho flexible schema (sao, cung data)
- Good indexing
- ACID compliance
- Full-text search capability

## 4. Câu Hỏi Về Độ Chính Xác

### Q11: Độ chính xác của Tử Vi là bao nhiêu?

**A:** Độ chính xác phụ thuộc vào nhiều yếu tố:

**Yếu tố ảnh hưởng:**

| Yếu tố | Mức độ | Giải pháp |
|--------|--------|-----------|
| Giờ sinh chính xác | **Rất cao** | Cần rõ ràng sáng/chiều/tối/đêm |
| Múi giờ | **Cao** | Sử dụng IANA timezone |
| Ngày âm lịch | **Cao** | Correct lunar calendar |
| Leap month | **Trung bình** | Xác định đúng tháng nhuận |

**Ước tính độ chính xác:**
- Giờ sinh chính xác (±15 phút): ~90%
- Giờ sinh khung giờ (sáng/chiều/tối): ~75%
- Giờ sinh ước lượng: ~50-60%

**Lưu ý:**
- Tử Vi nhạy cảm với giờ sinh hơn Bát Tự
- Sai giờ có thể thay đổi nhiều sao trong cung

### Q12: Tại sao cùng ngày sinh nhưng lá số khác nhau?

**A:** Có thể do:

**1. Khác giờ sinh:**
- Cùng ngày nhưng khác giờ → Sao nhập cung khác
- Giờ Tý (23:00-01:00) vs Giờ Ngọ (11:00-13:00) cho ra 2 lá số rất khác nhau

**2. Khác múi giờ:**
- Sinh ở Việt Nam vs Nhật Bản cùng giờ UTC
- Cần chuyển về giờ địa phương

**3. Khác ngày âm lịch:**
- Gần Tết Nguyên Đán
- Tháng nhuận

**4. Khác giới tính:**
- Nam/Nữ khác Cung Mệnh
- Dẫn đến vị trí 12 Cung khác nhau

**5. Library tính toán khác nhau:**
- Cách tính âm lịch khác nhau
- Thuật toán xác định sao khác nhau

### Q13: Nên tin tưởng Tử Vi ở mức nào?

**A:** Tử Vi nên được xem là **tham khảo**:

**Nên dùng để:**
- Hiểu bản thân (điểm mạnh/yếu tính cách)
- Xác định hướng phát triển phù hợp
- Hiểu xu hướng vận mệnh theo thời gian
- Tham khảo thời điểm tốt cho việc quan trọng

**Không nên dùng để:**
- Quyết định hôn nhân (dựa vào tình cảm thực tế)
- Chọn nghề nghiệp duy nhất
- Đầu tư tài chính lớn dựa hoàn toàn
- Thay thế tư vấn chuyên môn
