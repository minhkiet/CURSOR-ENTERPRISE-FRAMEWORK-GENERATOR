# RAG Glossary - Từ Điển Thuật Ngữ RAG

## Giới thiệu

Tài liệu này cung cấp các thuật ngữ chuyên ngành RAG (Retrieval-Augmented Generation).

## Các thuật ngữ cơ bản

### 1. RAG

RAG (Retrieval-Augmented Generation) là technique kết hợp retrieval system với LLM. Model access relevant documents từ knowledge base. Reduces hallucinations.

### 2. Vector Database

Vector database stores embeddings và enables similarity search. Pinecone, Weaviate, pgvector, Milvus. Essential for RAG.

### 3. Embeddings

Embeddings là numerical representations của text. Generated by embedding models. Similar text có similar vectors.

### 4. Chunking

Chunking là process chia documents thành smaller pieces. Affects retrieval quality. Strategies: fixed size, semantic, recursive.

### 5. Retrieval

Retrieval là process tìm relevant documents từ knowledge base. Vector similarity, keyword search, hybrid.

### 6. Generation

Generation là process tạo response using retrieved context. LLM synthesizes information.

### 7. Reranking

Reranking là process reorder retrieved results. Semantic relevance > keyword similarity.

### 8. Hybrid Search

Hybrid search kết hợp vector similarity và keyword matching. Best of both approaches.

## Kết luận

RAG Glossary cung cấp nền tảng về RAG systems.
