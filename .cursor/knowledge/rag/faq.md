# RAG FAQ - Câu Hỏi Thường Gặp RAG

## Câu Hỏi Cơ Bản

### 1. RAG là gì?

RAG (Retrieval-Augmented Generation) là technique kết hợp retrieval system với LLM. Model access relevant documents từ knowledge base.

### 2. Chunking là gì?

Chunking là process chia documents thành smaller pieces. Affects retrieval quality.

### 3. Embeddings là gì?

Embeddings là numerical vectors representing text. Generated by embedding models.

## Câu Hỏi Kỹ Thuật

### 4. Chunk size nào?

Typical sizes: 512-1024 tokens. Experiment để find optimal.

### 5. Vector DB nào?

Pinecone, Weaviate, pgvector, Milvus. Choose based on scale và features.
