# Vue Checklist - Danh Sách Kiểm Tra Vue

## Checklist Development

### Setup

- [ ] Vue project initialized
- [ ] TypeScript configured
- [ ] Linting setup (ESLint + Prettier)
- [ ] Vue Router configured
- [ ] Pinia configured

### Components

- [ ] Components use script setup
- [ ] Props have type definitions
- [ ] Events are properly emitted
- [ ] Slots used appropriately

### State

- [ ] Pinia stores organized
- [ ] Reactive state properly used
- [ ] Computed properties optimized
- [ ] Watchers used correctly

### Performance

- [ ] Lazy loading configured
- [ ] Components optimized
- [ ] Bundle size monitored
- [ ] Images optimized

## Checklist Testing

- [ ] Unit tests written
- [ ] Component tests written
- [ ] E2E tests written
- [ ] Coverage targets met

## Checklist Security

- [ ] XSS prevention
- [ ] Input validation
- [ ] Auth implemented
- [ ] Secrets managed

## Kết luận

Use this checklist during Vue development.
