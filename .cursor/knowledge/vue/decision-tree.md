# Vue Decision Tree - Cây Quyết Định Vue.js

## Quyết định về Project Setup

### Câu hỏi: Vue 2 hay Vue 3?

- **Vue 3 (Recommended)**
  - Modern features
  - Better TypeScript
  - Active development

### Câu hỏi: Vue Router?

- **Yes** cho apps với multiple pages
- **No** cho simple pages

### Câu hỏi: State Management?

- **Pinia** cho Vue 3 (recommended)
- **Vuex** cho Vue 2 (legacy)

## Quyết định về Styling

- **Tailwind CSS** cho utility-first
- **SCSS** cho traditional
- **CSS Modules** cho scoped

## Quyết định về Build Tool

- **Vite** (recommended)
- **Vue CLI**

## Summary

Vue 3 + Pinia + Vite là recommended stack.
