# Customer Rules - Quy tắc khách hàng

## Mô tả
Lưu trữ các quy tắc và yêu cầu đặc thù của từng khách hàng, giúp AI agent customize behavior theo từng khách hàng.

## Quy tắc chung
- [ ] Mỗi khách hàng có unique customer_id
- [ ] Customer profile lưu preferences và requirements
- [ ] Customer-specific rules override global rules
- [ ] Customer data được isolate hoàn toàn
- [ ] Audit log cho mọi thay đổi

## Tùy chỉnh giao diện
- [ ] Branded theme: colors, fonts, logos
- [ ] Custom domain
- [ ] Email template branding
- [ ] Report template customization
- [ ] Dashboard widget configuration

## Tùy chỉnh nghiệp vụ
- [ ] Custom field definitions
- [ ] Custom workflow steps
- [ ] Custom validation rules
- [ ] Custom notification rules
- [ ] Custom API endpoints

## Tùy chỉnh AI/RAG
- [ ] Custom knowledge base per customer
- [ ] Custom embedding model
- [ ] Custom retrieval prompt
- [ ] Custom response format
- [ ] Custom tone và style

## Security Rules
- [ ] SSO configuration (SAML, OIDC)
- [ ] IP whitelist/blacklist
- [ ] Session timeout rules
- [ ] Password policy
- [ ] 2FA enforcement

## Compliance Rules
- [ ] GDPR compliance
- [ ] SOC 2 compliance
- [ ] ISO 27001 compliance
- [ ] Data retention policy
- [ ] Data residency requirements

## Integration Rules
- [ ] Allowed third-party integrations
- [ ] API rate limits per customer
- [ ] Webhook configuration
- [ ] SSO provider configuration

## Support Rules
- [ ] SLA tiers: Basic, Standard, Premium, Enterprise
- [ ] Support channel: email, chat, phone
- [ ] Response time SLAs
- [ ] Escalation rules
- [ ] Knowledge base access level
