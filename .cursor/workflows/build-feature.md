# Workflow: Build Feature - Xây dựng Feature

## Mục tiêu
Workflow chuẩn để xây dựng một feature mới từ đầu đến cuối.

## Trigger
Khi user yêu cầu xây dựng feature mới.

## Workflow Steps

### Bước 1: Requirement Analysis
- [ ] Understand feature requirements
- [ ] Identify domain
- [ ] Load relevant knowledge
- [ ] Check existing similar features
- [ ] Document requirements

### Bước 2: Architecture Design
- [ ] Design data model
- [ ] Design API endpoints
- [ ] Design component structure
- [ ] Check/create ADR if needed

### Bước 3: Implementation
- [ ] Setup development environment
- [ ] Implement backend (if needed)
- [ ] Implement frontend (if needed)
- [ ] Write tests
- [ ] Run linters

### Bước 4: Verification
- [ ] Run unit tests
- [ ] Run integration tests
- [ ] Manual testing
- [ ] Code review

### Bước 5: Documentation
- [ ] Update README
- [ ] Update API docs
- [ ] Update knowledge base
