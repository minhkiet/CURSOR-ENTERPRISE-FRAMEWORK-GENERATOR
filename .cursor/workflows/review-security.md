# Workflow: Review Security - Review bảo mật

## Mục tiêu
Workflow chuẩn để thực hiện security review.

## Trigger
Khi user yêu cầu security review.

## Workflow Steps

### Bước 1: Scope
- [ ] Define security scope
- [ ] Load security knowledge
- [ ] Identify attack surfaces

### Bước 2: Threat Modeling
- [ ] Identify assets
- [ ] Identify threats
- [ ] Assess risks

### Bước 3: Testing
- [ ] Authentication testing
- [ ] Authorization testing
- [ ] Input validation testing
- [ ] Configuration review

### Bước 4: Report
- [ ] Document vulnerabilities
- [ ] Prioritize by severity
- [ ] Provide remediation
