# Command: /audit

## Mục tiêu
Audit toàn diện về security, performance, architecture, hoặc database.

## Trigger Keywords
- audit
- security audit
- performance audit
- architecture audit
- database audit
- kiểm toán
- security review
- vulnerability scan
- penetration test

## Audit Types

### /audit security
- [ ] Load security-review skill
- [ ] Load security rules
- [ ] Check OWASP Top 10
- [ ] Check for common vulnerabilities
- [ ] Check authentication/authorization
- [ ] Check input validation
- [ ] Check secrets management
- [ ] Provide remediation plan

### /audit performance
- [ ] Load performance-audit skill
- [ ] Check database queries (N+1, missing indexes)
- [ ] Check caching strategy
- [ ] Check bundle size
- [ ] Check API latency
- [ ] Check resource usage
- [ ] Provide optimization recommendations

### /audit architecture
- [ ] Load architecture rules
- [ ] Check design patterns
- [ ] Check component boundaries
- [ ] Check dependency management
- [ ] Check scalability
- [ ] Provide refactoring recommendations

### /audit database
- [ ] Load postgres/mysql/sql-server rules
- [ ] Check schema design
- [ ] Check indexes
- [ ] Check query performance
- [ ] Check backup/recovery
- [ ] Provide optimization recommendations
