# Command: /design

## Mục tiêu
Thiết kế kiến trúc hệ thống với các patterns phù hợp.

## Trigger Keywords
- design
- thiết kế
- architecture design

- cqrs design
- database design
- api design
- system design
- clean architecture
- hexagonal architecture

## Design Types

### /design ddd
- [ ] Load ddd-design skill
- [ ] Identify bounded contexts
- [ ] Define aggregates
- [ ] Define entities & value objects
- [ ] Define domain events
- [ ] Design repositories
- [ ] Design application services
- [ ] Create ADR

### /design cqrs
- [ ] Load cqrs-implementation skill
- [ ] Identify commands vs queries
- [ ] Design command handlers
- [ ] Design query handlers
- [ ] Design event bus
- [ ] Create ADR

### /design database
- [ ] Load database rules (postgres/mysql/sql-server)
- [ ] Design schema
- [ ] Design indexes
- [ ] Design migrations
- [ ] Check normalization
- [ ] Create ADR

### /design api
- [ ] Load api, restful-api, graphql rules
- [ ] Design endpoints/resources
- [ ] Design request/response contracts
- [ ] Design error handling
- [ ] Design versioning
- [ ] Create ADR

### /design clean
- [ ] Load clean-architecture skill
- [ ] Design layers (entities, use cases, interfaces, infrastructure)
- [ ] Design dependency direction
- [ ] Create ADR
