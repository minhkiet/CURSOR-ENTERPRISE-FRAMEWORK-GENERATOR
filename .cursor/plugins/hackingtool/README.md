# Vibe Framework Security & Pentest Plugin (Hackingtool Suite)

Integrates 183+ OSINT & Pentesting tools into Cursor IDE, Claude Code, and Antigravity.

## Features
- **Passive OSINT Reconnaissance**: Subdomain enumeration (subfinder, amass), username dossier gathering (sherlock, maigret).
- **Network Probing**: Service detection & port exploration (nmap, masscan).
- **Vulnerability Assessment**: Template-based scans (nuclei), SQL injection verification (sqlmap), secret leakage detection (trufflehog).
- **Marketplace Compliant**: Serves as the plugin source for `.claude-plugin/marketplace.json`.
