# Vibe Framework Spec Kit Plugin

Enforces Spec-Driven Development (SDD) following the 7-phase lifecycle (Constitution -> Specify -> Clarify -> Plan -> Checklist -> Tasks -> Implement).

## Features
- **Spec Init**: Scaffolds structured `spec.md`, `plan.md`, and `tasks.md` under `.specify/`.
- **Spec List**: High-level inventory of all active and completed feature specifications.
- **Spec Status**: Tracks checklist progress, open edge cases, and completed tasks.
- **Spec Validation**: Validates implementation artifacts against Constitution quality rules.
- **Constitution Viewer**: Displays core engineering constitution and quality gates.
