# Northwind CRM — Landing Page Demo

Landing page React/Next.js cho vertical CRM, áp dụng toàn bộ nguyên tắc "Market Pro 2026 / Anti-AI-Slop".

## Stack

- **Next.js 14** (App Router)
- **React 18** + TypeScript
- **Tailwind CSS 3.4** với custom tokens (slate + ink + accent indigo)
- **Phosphor Icons** (filled + regular + bold weights)

## Cài đặt

```bash
cd demos/crm
npm install
npm run dev
# → http://localhost:3004
```

## Vertical Voice (Northwind CRM)

- **Tone**: Professional cockpit · data-dense · KPI-first
- **Keywords**: Pipeline · Forecast · Win rate · Deal velocity · Activity feed
- **Numbers-first**: "47,8 tỷ VND" / "+18,2%" / "92% accuracy"
- **Vietnamese diacritics đầy đủ**, currency format `1.250.000₫` tabular-nums

## Anti-patterns đã tránh

- ❌ 3 equal cards (đã bento asymmetric ở mọi section)
- ❌ Generic hero copy "Make every screen feel like..." (đã KPI-specific)
- ❌ Random `picsum.photos` placeholders (đã Unsplash curated + Simple Icons CDN)
- ❌ No keyboard accessibility (đã aria-keyshortcuts, focus rings, role=dialog)
- ❌ Color-only status (đã icon + text + color)
- ❌ Sparkline không có text alt (đã `role="img"` + `aria-label`)
- ❌ "Generated by AI" empty feeling (đã data density + real metrics)

## Performance notes

- Avatar Unsplash `loading="lazy"` + 80q
- Simple Icons CDN cached
- SVG sparkline inline (no request)
- Bento dùng CSS Grid auto-rows (no JS layout)
- Avatar group on hero: 3 stacked với ring
- Mobile-first responsive với `lg:` breakpoints
- Static export ready (`next build`)

## Accessibility (WCAG 2.2 AA)

- `<html lang="vi">`
- Skip-to-content ready (thêm nếu cần)
- All hero KPIs `tabular-nums`
- Pipeline stages `<section>` + `aria-labelledby`
- Pricing tiers monthly/annual `role="tablist"` + `aria-selected`
- Footer hotline `tel:` + email `mailto:`
- Trust signals có icon + label
- Reduce-motion: transitions + animations off
- Focus rings: `focus:ring-2 focus:ring-indigo-500`
