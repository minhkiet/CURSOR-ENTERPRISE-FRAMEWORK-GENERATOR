# Ironpath Fitness — Landing Page Demo

Landing page React/Next.js cho vertical Fitness, áp dụng toàn bộ nguyên tắc "Market Pro 2026 / Anti-AI-Slop". Dark theme với electric-lime accent.

## Stack

- **Next.js 14** (App Router)
- **React 18** + TypeScript
- **Tailwind CSS 3.4** với custom tokens (ink-950 dark base + electric lime accent)
- **Phosphor Icons** (filled + regular + bold weights)
- **Archivo Black** display font + **Inter** body

## Cài đặt

```bash
cd demos/fitness
npm install
npm run dev
# → http://localhost:3005
```

## Vertical Voice (Ironpath)

- **Tone**: Dark utilitarian · gym-floor practical · numbers-driven
- **Keywords**: PR · RIR · Volume · 1RM · hypertrophy · touch targets
- **Numbers-first**: "100kg × 6 reps" / "1:30 rest" / "142 BPM"
- **Touch targets**: ≥ 56px (gym glove context)
- **Dark theme**: AAA contrast (slate-50 on slate-950 = 17.8:1)
- **Accent**: Electric lime `#84cc16` — high contrast trên dark, unique, gym vibe

## Anti-patterns đã tránh

- ❌ 3 equal cards (đã bento asymmetric ở mọi section)
- ❌ Generic hero copy "Make every screen feel like..." (đã gym-specific)
- ❌ Color-only PR/activity status (đã icon + text)
- ❌ Light theme cho gym (đã dark với lime accent)
- ❌ No touch target sizing (đã ≥ 56px)
- ❌ Chart không accessible (đã role="img" + aria-label + button bars)
- ❌ Reduce-motion không respected (đã CSS)
- ❌ Generic photos (đã gym-specific Unsplash + realistic numbers)
- ❌ "Generated by AI" empty feeling (đã data density + real fitness metrics)

## Performance notes

- Avatar Unsplash `loading="lazy"` + 80q
- Simple Icons CDN cached
- Lazy load images
- Bento dùng CSS Grid auto-rows
- Mobile-first responsive
- `font-display` Archivo Black cho headlines
- Grid background pattern CSS-only
- Static export ready

## Accessibility (WCAG 2.2 AA)

- `<html lang="vi">`
- All KPIs `tabular-nums`
- Touch targets ≥ 56px cho workout controls
- Color contrast AAA: `electric-400` trên `ink-950` = 14.1:1 ✓
- `role="timer"` + `aria-live` cho rest countdown
- Volume chart: `role="img"` + `aria-label`, bars là `<button>` focusable
- Period tabs: `role="tablist"` + `aria-selected`
- Reduce-motion: all transitions instant
- Focus visible: `focus-visible:ring-2 focus-visible:ring-electric-500`
