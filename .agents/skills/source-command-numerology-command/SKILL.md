# source-command-numerology-command

Use this skill when the user asks to run the migrated source command `numerology-command`.

## Command Template

# Command: /numerology

## Mục tiêu
Tính Thần Số Học (Numerology) cho dự án liên quan đến metaphysics.

## Trigger Keywords
- numerology
- thần số học
- số chủ đạo
- life path
- destiny number
- soul urge
- personality number
- expression number
- số mệnh
- số tên
- số ngày sinh

## Tính năng

### /numerology calculate
- [ ] Nhập họ tên đầy đủ
- [ ] Nhập ngày sinh
- [ ] Tính Số Chủ Đạo (Life Path Number)
- [ ] Tính Số Số Mệnh (Destiny/Expression Number)
- [ ] Tính Số Tâm Hồn (Soul Urge Number)
- [ ] Tính Số Nhân Cách (Personality Number)
- [ ] Phân tích ý nghĩa các con số

### /numerology compatibility
- [ ] Tính tương hợp giữa hai người
- [ ] Phân tích số chủ đạo
- [ ] Đánh giá mức độ hợp
