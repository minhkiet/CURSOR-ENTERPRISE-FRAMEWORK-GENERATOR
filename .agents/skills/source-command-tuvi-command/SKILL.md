# source-command-tuvi-command

Use this skill when the user asks to run the migrated source command `tuvi-command`.

## Command Template

# Command: /tuvi

## Mục tiêu
Tính Tử Vi (Vietnamese/Chinese Astrology) cho dự án liên quan đến metaphysics.

## Trigger Keywords
- tuvi
- tử vi
- vietnamese astrology
- chinese astrology
- lá số tử vi
- sao chiếu
- cung mệnh
- mệnh cách
- tử vi đẩu
- vận trình
- lưu niên
- đại vận
- tiểu vận

## Tính năng

### /tuvi calculate
- [ ] Nhập thông tin: năm sinh, tháng sinh, ngày sinh, giờ sinh, giới tính
- [ ] Xác định Mệnh (cung mệnh)
- [ ] Xác định Thân (cung thân)
- [ ] Đặt các sao: Tử Vi, Liêm Trinh, Thiếu Dương, etc.
- [ ] Xác định tứ Hóa
- [ ] Xác định tứ Cung
- [ ] Phân tích vận trình

### /tuvi chart
- [ ] Generate lá số tử vi
- [ ] Hiển thị cung mệnh, cung thân
- [ ] Hiển thị các sao chiếu
- [ ] Hiển thị vận trình
