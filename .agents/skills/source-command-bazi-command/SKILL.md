# source-command-bazi-command

Use this skill when the user asks to run the migrated source command `bazi-command`.

## Command Template

# Command: /bazi

## Mục tiêu
Tính Bát Tự (Four Pillars of Destiny) cho dự án liên quan đến Vietnamese metaphysics.

## Trigger Keywords
- bazi
- bát tự
- four pillars
- lá số
- tử vi bát tự
- destiny calculation
- cung mệnh
- vận số
- ngũ hành
- thiên can
- địa chi
- thập can
- thập nhị chi

## Tính năng

### /bazi calculate
- [ ] Nhập thông tin: năm sinh, tháng sinh, ngày sinh, giờ sinh
- [ ] Tính Thiên Can (Year/Month/Day)
- [ ] Tính Địa Chi (Year/Month/Day)
- [ ] Tính Ngũ Hành (sinh, hành, chưng)
- [ ] Xác định Tứ Trụ
- [ ] Xác định Niên Can
- [ ] Phân tích cung mệnh
- [ ] Phân tích vận trình

### /bazi compatibility
- [ ] Tính tương hợp giữa hai người
- [ ] Phân tích ngũ hành tương sinh/tương khắc
- [ ] Đánh giá mức độ hợp

### /bazi career
- [ ] Phân tích xu hướng nghề nghiệp
- [ ] Đề xuất hướng phát triển
- [ ] Thời điểm tốt cho sự nghiệp
