## Frontend Task Types

### /frontend landing (frontend-taste)
- [ ] Pre-review gate (Section 0.A - 0.F)
- [ ] Design read declaration
- [ ] Dial values: VARIANCE / MOTION / DENSITY
- [ ] Anti-default discipline
- [ ] Design system selection
- [ ] Implementation
- [ ] Post-review gate (Section 6.A - 6.H)
- [ ] Design & taste review
- [ ] Accessibility review
- [ ] Performance review

### /frontend redesign (frontend-redesign)
- [ ] Pre-review gate (Section 0.A - 0.E)
- [ ] Framework & styling identification
- [ ] Brand token extraction
- [ ] Redesign mode classification
- [ ] Implementation
- [ ] Post-review gate (Section 4.A - 4.E)
- [ ] Functionality preserved
- [ ] Design quality
- [ ] SEO preserved

### /frontend review (frontend-review)
- [ ] Pre-review gate (Part A: A.1 - A.3)
- [ ] Scope analysis
- [ ] Quality plan
- [ ] Implementation review
- [ ] Post-review gate (Part B: B.1 - B.7)
- [ ] Correctness, design, accessibility, performance, state, testing

### /frontend full (full-output)
- [ ] Pre-review gate (Section 0.A - 0.B)
- [ ] Scope lock (N deliverables)
- [ ] Implementation
- [ ] Post-review gate (Section 5.A - 5.C)
- [ ] Completeness, quality, file structure
